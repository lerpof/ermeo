# ermeo_api_client

Dio HTTP client and models generated from `openapi/openapi.yaml` (fetched from `GET /openapi.yaml`).

Regenerate from `ermeo/packages/ermeo_api`:

```bash
# Requires Java 8+
cd ../../../.. && melos run generate:api
```

This directory is a **committed bootstrap** until `openapi_generator` runs on a machine with Java installed.
