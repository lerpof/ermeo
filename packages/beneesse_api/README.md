# beneesse_api

Pure Dart package for API clients, DTOs, and networking. No Flutter dependency.

## Purpose

Placeholder for the Beneesse API layer (HTTP clients, models, and service contracts).

## Public API

None yet — `lib/beneesse_api.dart` exports an empty library stub.

## Dependency rules

- Consumed **only** by `apps/beneesse_mobile`.
- `beneesse_ui` and `beneesse_monitoring` must **not** depend on this package.
